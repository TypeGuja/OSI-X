# Интеграционные тесты OSIX Firmware

Каталог зарезервирован под интеграционные тесты (`tests/*.rs`), которые
запускаются через `cargo test` в режиме `std` (без реального железа —
хостовые unit-тесты для чистой логики: планировщик движения, парсер
G-Code, кинематика, регистры TMC2209).

Модульные тесты, не требующие железа, размещаются прямо в соответствующих
модулях (`#[cfg(test)] mod tests { ... }`) — см., например,
`src/config/mod.rs` и `src/logger/mod.rs`.

Тесты, требующие реального контроллера (HIL — hardware-in-the-loop),
появятся на этапе подключения `drivers/tmc2209` и `motion` и будут
описаны отдельно.
